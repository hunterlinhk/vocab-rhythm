# 韵词 Cadence｜下一阶段产品与工程路线图（审阅草案）

> 审计时间：2026-11-06｜基准：main @ 83edf56。本文是基于仓库代码、README、迁移、测试及 build-log 的静态审计，不构成生产站点或生产数据验收报告。此文档不授权自动执行生产迁移或发布。

## 产品判断

韵词应聚焦于面向中文学习者的「键盘流畅打字 → 语境理解 → 间隔复习 → 个性化反馈」，而不是依赖页面数量竞争。当前已存在单词拼写、句子拼写、背词三阶段、错词/今日复习、学习计划/统计、自建词库、认证与 AI 助手页面。AI 服务开关当前关闭（src/lib/learning.functions.ts）。根路径与 /home 刻意直达 /learn，不应未经验证就恢复强制 Dashboard。

**北极星指标候选**：每周至少完成两天有效学习的用户数。有效学习需明确为真实完成的练习/复习事件，排除跳过、重复上报和测试流量。先埋点建立基线，再制定数值目标。

## P0 — 生产可靠性与发布底座（第 1–2 周）

1. **生产环境只读核查与升级清单**
   - 核对当前生产数据库迁移账本、0013/0015/0017 等关键 schema、RPC 权限及 RLS；在核实可恢复备份前，不执行任何写入性迁移。
   - 重点验收 get_today_practice_count_v1 与 get_learning_stats_v1：时区、跨日、连续天数、误触/跳过、重复练习计数和匿名/越权访问。
   - 基于 docs/review-v1-rollout.md 与 docs/review-state-historical-repair.md 检查历史修复窗口和调度状态；不凭仓库文件存在就假定生产已升级。
   - 验收路径：访客/邮箱/Google（如后台启用）、单词/背词/句子、复习队列、自建与删除词书、资料与统计。
   - **完成标准**：形成生产环境只读核查记录、迁移状态/风险清单与可重复 E2E 验收报告；所有 P0 阻断问题关闭。

2. **自动化质量门禁**
   - 新建 GitHub Actions，PR 必须通过 lint、test、TypeScript 与 build；明确使用 bun.lock 的锁定安装与运行时版本。
   - 针对核心路径补浏览器级 E2E（移动端虚拟键盘、输入法、网络失败、会话恢复、离线/超时、同词跨词书与时区）。
   - 分支开发、审查 PR、灰度/回滚、禁止改写已发布的 Lovable 同步历史。
   - **完成标准**：新 PR 自动检查可见，合并前可阻断回归；在生产与测试之间明确迁移操作职责。

3. **配置与安全清理**
   - 当前版本库追踪 .env，已检到的变量名为 Supabase URL、Project ID 和 publishable key；未发现服务角色密钥变量名。迁移为示例文件并检查历史提交是否包含真正的机密。
   - 服务端 privileged key 只保留在安全的部署环境，确认用户鉴权、RLS、资源所有权限制。
   - **完成标准**：环境变量分类与部署检查表已文档化，无已知秘密写入仓库。

## P1 — 先完善学习内容与留存体验（第 2–5 周）

4. **NGSL 内容补全：先完成高频 300，再逐步扩展至 1,000 / 2,809**
   - src/data/ngsl-1.2-stats.csv 的 2,809 条统计数据是完整来源，但 src/data/ngsl-1.2-learning.ts 目前为空；现有 OEWN 文档仅确认 26 个经过审核的主词义可直接用于学习字段。
   - 对首批 300 词逐词核对中文释义、词性、常用发音、自然例句和中文译文；多义词要选择符合学习顺序的义项，保留来源与人工审核状态。
   - 背词模式必须对缺少释义/例句的词给出合理降级或过滤，避免看似完整却无法答题。
   - **完成标准**：首批 300 词关键字段覆盖率 100%，拼写/背词/句子流程可完整体验；内容质量抽样复核通过；许可署名可追溯。

5. **学习到复习的核心闭环**
   - 在 /learn 保持立即进入输入的速度，在合适位置呈现今日进度、下一组复习任务和学习结束反馈，而不是新增强制首页。
   - 清晰区分“今日练习次数”“首次学会的不同单词数”“待复习量”“复习完成量”，避免用户重复练同词造成认知误差。
   - 验证匿名用户升级为正式账号时学习历史、复习队列和自建词库是否安全保留；若未支持，先明确说明再开放升级入口。
   - **完成标准**：首次访客可开始学习，完成一组训练后知道下一步，次日回访能找到真实待复习任务；关键数据跨会话一致。

6. **用户体验与反馈机制**
   - 核验中英文输入法、手机虚拟键盘与焦点行为；支持常见键盘导航和减少动画设置。
   - 增加轻量问题反馈入口，不收集用户输入的密码或不必要学习对话内容。
   - **完成标准**：桌面和移动主流浏览器关键路径 E2E 通过；高优先级可用性问题有复现与修复记录。

## P2 — AI 与增长验证（第 5–8 周）

7. **受控开放 AI 学习助手**
   - 当前 AI_ASSISTANT_ENABLED=false；上线前做模型连接有效性校验、按用户限流/成本预算、超时与错误状态、提示注入隔离、敏感记录最小化、生成内容事实准确性抽检。
   - 先围绕用户真实错词做三项高价值能力：解释错因、生成适合水平的例句、生成可回写复习状态的小测试。不要一开始推出无边界通用聊天。
   - **完成标准**：灰度用户可完成三条 AI 闭环；成本、失败率、响应延迟与数据隐私有可观测指标，提供一键关闭能力。

8. **公开产品页与增长分析**
   - 保留注册后直达学习的内部流程，新增不干扰学习的公开介绍页，解释“打字 + 间隔复习 + AI”的价值，并提供立即体验入口。
   - 建立隐私友好的匿名事件口径：访问 → 体验开始 → 首组完成 → 注册 → 次日返回 → 7 日返回 → 复习完成。避免把练习答案、完整对话作为事件属性。
   - 先做小规模中文学习者访谈和邀请测试，再评估 Pro 付费权益；不急于引入支付系统。
   - **完成标准**：能按来源观察从体验到回访的漏斗；有实际用户反馈支持下轮优先级决策。

## 关键验收指标（先收集基线，不虚构现值）

| 指标 | 推荐定义 |
| --- | --- |
| 首组完成率 | 首次开始练习的用户中，完成约定训练组的比例 |
| D1 / D7 留存 | 第 0 天首次有效学习的用户中，在次日/第 7 日再次有效学习的比例 |
| 复习完成率 | 当天有到期任务的用户中，至少完成一组到期任务的比例 |
| 学习内容覆盖 | 可用于指定模式的词条数 / 目标词条数；分别统计中文释义、词性、音标、例句 |
| 质量指标 | 核心流程错误率、数据写入失败率、AI 调用失败率、迁移验证通过率 |
