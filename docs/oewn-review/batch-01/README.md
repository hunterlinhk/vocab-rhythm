# OEWN 第一批词义审核

基线 main: 83edf56cbe45fdd95ad7aab54565c6e921fb8e47。选取 NGSL SFI 排名最高的 50 个无 reviewed pilot、具有精确 OEWN headword 匹配的词，排名 2–75。共 599 个候选 senses。现有 26 个 pilot 全部排除且保持不变。

## 如何审核

工作簿“逐词审核”每词一行；黄色列供填写结论、最终主 sense ID、备注。“全部候选”保留每个候选的原始英文释义、来源例句、IPA 和 source entry ref，可按词头筛选。建议是教学取舍，不是 OEWN 频率排名或已批准结果；NGSL 排名只针对词头，不确定各义项的频率。所有人工结论初始均为待审核。

本轮没有修改任何 priority、pilot、导入 SQL、学习页面或数据库。缺例句／IPA明确标为来源未提供。导入包只保留每个 sense 的首条定义及首条可用 synset 例句，因此此表不声称覆盖 OEWN 归档里的所有例句；例句可能使用同义词而非目标词，审批时需检查能否直接用于目标词练习，不能自行替换词语。sense ID 以源 sense_key 为准，不能从 ID 大小或排列顺序推断频率。
